# ah ti koza

A pixel goat choir. Take the quiz ("какая ты коза?"), get your archetype, add your named goat to the snowy field, and sing along with the other goats — each archetype plays its own part of the song.

- `out/goat-choir.html` — the app (open in a browser, works offline except the pixel font)
- `out/goat-choir-demo.html` — same app with 40 test goats in every group
- `web/pen/` — source: goats, choir layout, quiz, audio engine, terrain

Build:

```bash
npm install
npm run build:html
```
